🔥 Jewiish Apparel
A modern fashion and streetwear website built for Jewiish Apparel, a South African clothing brand inspired by ambition, resilience, and the spirit of fire.

✨ Features
Modern React UI
TypeScript for type safety
Vite for fast development
Responsive design
Fire-inspired branding
Product showcase
Events section
Gallery section
🛠️ Tech Stack
React
TypeScript
Vite
CSS3
📂 Project Structure
src/
├── assets/
├── components/
├── App.tsx
├── main.tsx
└── index.css
🚀 Getting Started
Install Dependencies
npm install
Start Development Server
npm run dev
Build for Production
npm run build
Preview Production Build
npm run preview
